Before the first file

We learn how you work before we touch a file

Every title company does things its own way. So we start by writing yours down, and no work begins until you have approved it.

  1. 1

    You show us how you work

    Walk us through a file in your own software, or send us reference commitments and policies. From those we learn your wording and how you show each detail: deeds, mortgages, liens, chain of title, taxes and so on.

  2. 2

    We ask, then draft your SOP

    We raise every question about your process up front, then write it up as a standard operating procedure.

  3. 3

    You approve it, then we start

    We send the SOP to you for sign-off. Work on your files begins only once you have approved it.
